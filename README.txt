SMART WEDDING MANAGEMENT SYSTEM
================================

Project Type:
Java Swing OOP Project

Database:
No Database

Technology:
Java
Java Swing
OOP
ArrayList


FEATURES
========

1. Customer Management
   - Add Customer
   - Update Customer
   - Delete Customer
   - Search Customer

2. Guest Management
   - Add Guest
   - Update Guest
   - Delete Guest
   - Search Guest
   - Husband/Wife Relation
   - Spouse Information
   - Gift Information
   - Money Information

3. Package Management
   - Add Package
   - Update Package
   - Delete Package
   - Search Package

4. Venue Management
   - Add Venue
   - Update Venue
   - Delete Venue
   - Search Venue

5. Booking Management
   - Add Booking
   - Update Booking
   - Delete Booking
   - Search Booking

6. Payment Management
   - Add Payment
   - Update Payment
   - Delete Payment
   - Search Payment


GUEST SPECIAL FEATURE
=====================

When a guest is searched, the system shows:

Guest Name
Relation
Spouse Name
Spouse Relation
Gift Type
Gift Details


EXAMPLE
=======

Guest Name : Rahim
Relation   : Husband
Spouse     : Ayesha (Wife)
Gift Type  : Money
Gift       : 5000 Taka


HOW TO RUN
==========

1. Open the project in VS Code or IntelliJ IDEA.

2. Make sure Java JDK is installed.

3. Compile all Java files.

4. Run Main.java.


IMPORTANT
=========

All Java files must be inside the same folder.

No database is required.

The project uses ArrayList for storing data.
